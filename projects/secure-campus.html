Secure Campus Network

Cisco Packet TracerVLANsACLsOSPF Routing

The Problem

Large campus networks require strict security protocols to prevent unauthorized access, data breaches, and broadcast storms. A flat network architecture is highly vulnerable to internal threats and traffic congestion.

The Solution

Simulated a secure enterprise network topology using Cisco Packet Tracer. I segmented the network into Virtual LANs (VLANs) to separate student, faculty, and administrative traffic, ensuring that sensitive data remains isolated.

I configured Access Control Lists (ACLs) to act as firewalls, blocking unauthorized IP ranges from accessing specific network segments. Additionally, I implemented OSPF routing for efficient data flow between different subnets and VLANs.

What I Learned

This project allowed me to apply network security principles in a simulated environment. I gained practical experience in troubleshooting connectivity issues using command-line tools like ping and traceroute, and learned the importance of subnetting and route summarization.
