E-Book Store

Web AppFrontendE-CommerceSQL

The Problem

Buying physical books can be expensive and space-consuming. I wanted to build a platform where users can easily browse and purchase digital books.

The Solution

I built a fully functional E-Book Store interface. It features a dynamic catalog that pulls data from a database, a search bar to filter books by title or author, and a functional shopping cart that calculates totals dynamically.

Key Features

  • Dynamic product catalog.
  • Search and filter functionality.
  • Shopping cart with real-time price calculation.
