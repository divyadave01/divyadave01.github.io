IoT Laser Security System

Arduino/ESP32C++LDR SensorCircuit Prototyping

The Problem

Traditional security alarms are prone to false triggers and can be easily bypassed by intruders. Many low-cost solutions lack the reliability required for consistent perimeter security.

The Solution

Designed and prototyped a hardware-software tripwire system using a laser transmitter and a Light Dependent Resistor (LDR) sensor. When the laser beam is interrupted by an object or person, the microcontroller instantly detects the voltage drop and triggers a localized buzzer alarm.

The system is designed to be low-cost, highly reliable, and easy to deploy across doorways or perimeters. It includes a reset mechanism to silence the alarm once the breach has been addressed.

What I Learned

This project provided hands-on experience with analog-to-digital signal processing. I learned how to debounce sensor inputs in code to prevent false alarms caused by sudden environmental changes (like shadows or dust). I also gained practical skills in circuit prototyping and hardware-software integration.
